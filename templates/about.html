What is Spam Detection?

Spam detection is the automated identification of unsolicited, harmful, or fraudulent messages. Attackers often distribute phishing scams, bogus lottery claims, and malicious URLs disguised as urgent personal or commercial SMS.

Our classifier processes textual attributes, frequency distributions, and keyword patterns (e.g. "claim", "urgent", "prize", "free") to distinguish legitimate conversation from fraudulent attempts.

What is Machine Learning?

Machine Learning (ML) enables computer systems to learn patterns and make predictions directly from historical data without being explicitly programmed with rigid hardcoded rules.

Using Supervised Learning, the model examines thousands of human-verified SMS messages labeled as ham or spam, learning the mathematical correlation between specific word occurrences and message classifications.

Technologies Used & Rationale

Python 3.9+ & Flask

Provides a lightweight, high-performance WSGI microframework for REST routing, API responses, and Jinja2 templating.

Scikit-Learn (TF-IDF & Logistic Regression)

Converts raw text into numerical feature matrices via Term Frequency-Inverse Document Frequency and evaluates class probabilities.

SQLite & Joblib

Zero-configuration, serverless relational database for audit records paired with Joblib for efficient model artifact persistence.

Bootstrap 5 & Vanilla JS

Responsive mobile-first layout engine with asynchronous AJAX (Fetch API) for seamless, page-reload-free interactions.
